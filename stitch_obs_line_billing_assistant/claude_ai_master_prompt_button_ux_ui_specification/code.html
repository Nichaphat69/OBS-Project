## 📌 1. BUSINESS DOMAIN & CONTEXT
- ระบบ: OBS (Outsource Billing System) สำหรับพนักงาน Outsource, PM/Supervisor, Admin และ บัญชี
- ลูกค้านำร่อง: บริษัท ไทยประกันชีวิต จำกัด (มหาชน) — สัญญา 26/B0113 (BAU Project)
- ตัวละครหลัก:
  - พนักงาน Outsource (เช่น คุณพงศ์พันธ์ มามาก - Dev / Java Programmer)
  - PM / Supervisor (เช่น คุณปิติกร ชุมภูชนะภัย)
  - ผู้ตรวจระบบ / บัญชี (Admin iPassion)
- กฎคิดเงิน Manday: เรทรายเดือนเต็มจำนวน (50,000 บาท) หักส่วนลดวันลา (เรท/วันทำงานมาตรฐาน 20 วัน = 2,500 บ./วัน)

## ⚡ CRITICAL ARCHITECTURE: PUSH NOTIFICATIONS VS USER ACTIONS
⚠️ ข้อกำหนดสำคัญที่ห้ามสับสน:
1. "การแจ้งเตือนรอบบิลส่ง Timesheet (3 ปุ่มตัวเลือก)" และ "การแจ้งเตือน Timesheet ยังไม่ส่ง":
   - ทั้ง 2 รายการนี้เป็น **Automated Trigger / Push Notification (Cron Scheduler หลังบ้าน OBS)**
   - ส่งตรงเข้า LINE Chatbot อัตโนมัติทุกวันที่ 1 ของทุกเดือน ตามเงื่อนไขสัญญาของบริษัทลูกค้านั้นๆ (เช่น สัญญา บมจ.ไทยประกันชีวิต)
   - บอทส่งข้อความเปิดอัตโนมัติ: "สิ้นเดือนแล้วคุณส่ง Timesheet หรือยังน้าา"
   - **ไม่ได้เกิดจากการกดปุ่ม Quick Menu / Rich Menu ด้านล่างเด็ดขาด**
2. "การแจ้งเตือน Timesheet ยังไม่ส่ง":
   - เป็น Automated Daily/Deadline Reminder จาก Cron Job ของระบบ OBS ยิงเตือนผู้ใช้ที่ยังไม่ส่งเอกสาร
3. Quick Action Menu ด้านล่างหน้าจอแชท (User Triggers):
   - มีเพียง 3 เมนู ได้แก่ `[สรุปยอดวางบิล]`, `[Help]`, และ `[สถานะการวางบิล]` เท่านั้น

## 📱 2. SCREEN ARCHITECTURE & USER JOURNEY

### หน้าจอที่ 1: Main Chat & Dashboard (หน้าจอหลัก LINE OA)
- **Quick Action Menu (ด้านล่างแชท 3 เมนู)**:
  1. `[สรุปยอดวางบิล]`: แสดงการ์ดสรุปยอดเงินทั้งสัญญา 300,000 บาท, ชำระแล้ว 2/6 รอบ (100,000 บ.), งวดปัจจุบันรอตรวจ 50,000 บ.
  2. `[Help]`: เปิด Interactive Form กล่องรับเรื่องร้องเรียน/แจ้งปัญหา
  3. `[สถานะการวางบิล]`: เปิด Stepper สรุปกระบวนการ 5 ขั้นตอน
- **ฟีเจอร์ปุ่ม Help Action**:
  - เมื่อคลิก `[Help]` -> แสดงการ์ด "ศูนย์ช่วยเหลือ & แจ้งปัญหา"
  - Category Chips: `[ระบบขัดข้อง (Bug)]`, `[Manday ไม่ถูกต้อง]`, `[Timesheet มีปัญหา]`, `[ข้อเสนอแนะ]`
  - Textarea สำหรับพิมพ์รายละเอียด
  - ปุ่ม `[Submit Report]` (ส่งเรื่อง) & `[ยกเลิก]` (Cancel)

---

### หน้าจอที่ 2: Timesheet Submission Flow (⚡ Push Notification อัตโนมัติ ทุกวันที่ 1 ของเดือน)
- **Trigger**: Cron System หลังบ้าน OBS ยิง Push Notification อัตโนมัติทุกวันที่ 1 ตามสัญญา บมจ.ไทยประกันชีวิต
- **ข้อความทักทาย**: "สิ้นเดือนแล้วคุณส่ง Timesheet หรือยังน้าา"
- **การ์ดแจ้งเตือนหลัก**: "แจ้งเตือน Timesheet ประจำเดือน ก.ย. 2569" พร้อม 3 ปุ่มตัวเลือก Action:
  1. **ปุ่ม `[💻 ส่งผ่านระบบ OBS]`** (Primary Flow):
     - Action: ส่งข้อความ `💻 ส่งผ่านระบบ OBS`
     - LINE Bot Response: แสดงการ์ด "ระบบส่ง Timesheet (OBS Portal) [LINE Verified]" พร้อมปุ่ม `[Send Timesheet]`
     - Interaction: นำทางไปยัง Web Portal `1 · อัปโหลด Timesheet` ของระบบ OBS ให้ลากวางไฟล์ PDF
  2. **ปุ่ม `[✉️ ส่งผ่าน Email ด้วยตนเอง]`** (Manual Email):
     - Action: ส่งข้อความ `✉️ ส่งผ่าน Email ด้วยตนเอง`
     - LINE Bot Response: แสดงการ์ด "บันทึกการส่งผ่าน Email เรียบร้อย (แจ้งฝ่ายบัญชีแล้ว)" อีเมล: billing-account@company.com
  3. **ปุ่ม `[👥 ให้ผู้ดูแลเป็นคนส่ง]`** (Delegate):
     - Action: ส่งข้อความ `👥 ให้ผู้ดูแลเป็นคนส่ง`
     - LINE Bot Response: แสดงการ์ด "มอบหมายผู้ดูแลระบบเรียบร้อย (แจ้ง Admin แล้ว)" ระบบส่ง Event แจ้งเตือนไปยัง PM / Supervisor (คุณปิติกร)

---

### หน้าจอที่ 3: Manday Inspection & Rejection (กรณีตรวจไม่ผ่าน / ตีกลับ)
- **Trigger**: เมื่อ Admin กดยืนยัน "ตีกลับ (Reject)" ในระบบ OBS
- **Bot Alert**: แสดงการ์ด `⚠️ ตรวจ Manday ไม่ผ่าน • ตีกลับให้แก้ไข`
- **Rejection Reason Box**: แสดงข้อความจาก Admin เช่น *"เหตุผลของการลาไม่ถูกต้อง โปรดแก้ไข และส่งTimesheet เข้าสู่ระบบอีกครั้ง"* ระบุชื่อผู้ตรวจและ Timestamp
- **ปุ่ม Action**: `[ส่ง Timesheet / แก้ไขและส่งใหม่]` เพื่ออัปโหลดไฟล์แก้งวดเดิม (เอกสาร 2026060001)

---

### หน้าจอที่ 4: Timesheet Pending Reminder (⚡ Push Notification แจ้งเตือน Timesheet ยังไม่ส่ง)
- **Trigger**: ระบบ OBS Cron Scheduler ตรวจพบผู้ใช้ยังไม่อัปโหลด Timesheet ใกล้กำหนดเส้นตาย (Deadline Push Alert)
- **Bot Push Message**: แจ้งเตือนสถานะ "Timesheet ยังไม่ส่ง" แสดง Countdown กำหนดส่ง และปุ่ม Quick CTA สำหรับอัปโหลดทันที

---

### หน้าจอที่ 5: Billing Status & Invoice Tracker
- **Stepper 5 ขั้นตอน**:
  1. Timesheet ประจำเดือน (สำเร็จ)
  2. ตรวจ Manday (สำเร็จ)
  3. ออกใบแจ้งหนี้ FlowAccount (Drafted สำเร็จ)
  4. วางบิลส่งลูกค้า (ขั้นตอนปัจจุบัน - ร่างอีเมลและเอกสารแนบ)
  5. การรับชำระเงิน (Term 30 วัน - รอรับชำระ)
